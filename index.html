Introduction to C

C is a general-purpose programming language created by Dennis Ritchie in 1972. It's known for its efficiency, flexibility, and close-to-hardware programming capabilities.

Control Flow

Master conditional statements and loops in C programming

Conditional Statements

conditions.c 
#include <stdio.h>

int main() {
    int score = 85;
    
    if (score >= 90) {
        printf("Grade: A\n");
    } else if (score >= 80) {
        printf("Grade: B\n");
    } else if (score >= 70) {
        printf("Grade: C\n");
    } else {
        printf("Grade: F\n");
    }
    
    return 0;
}

Loops

loops.c 
#include <stdio.h>

int main() {
    printf("For loop:\n");
    for (int i = 1; i <= 5; i++) {
        printf("Iteration %d\n", i);
    }
    
    printf("\nWhile loop:\n");
    int j = 1;
    while (j <= 3) {
        printf("Count: %d\n", j);
        j++;
    }
    
    return 0;
}

Functions

Learn to create and use functions for modular programming

Function Basics

functions.c 
#include <stdio.h>

// Function declaration
int add(int a, int b);
void greet(char name[]);

int main() {
    int sum = add(5, 3);
    printf("Sum: %d\n", sum);
    
    greet("");
    
    return 0;
}

// Function definition
int add(int a, int b) {
    return a + b;
}

void greet(char name[]) {
    printf("Hello, %s!\n", name);
}
